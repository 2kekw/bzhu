# Дневник БЖУ — приложение для телефона

Все файлы из этой папки нужно положить на любой хостинг с HTTPS (без HTTPS установка и офлайн-режим не работают).

## Вариант A: GitHub Pages (бесплатно)

1. Зарегистрируйся на github.com.
2. Создай новый репозиторий (New repository), например `bzhu`, тип Public.
3. Нажми «uploading an existing file» и перетащи все файлы из этой папки (не саму папку, а файлы внутри неё). Нажми Commit changes.
4. Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save.
5. Через 1–2 минуты сайт будет доступен по адресу `https://ТВОЙ_ЛОГИН.github.io/bzhu/`.

## Вариант Б: свой сервер

Положи файлы в любую папку веб-сервера (nginx, IIS и т. п.) с рабочим HTTPS-сертификатом.
Файлу `manifest.webmanifest` желательно отдавать тип `application/manifest+json`.

## Установка на телефон

- **Android (Chrome):** открой адрес → меню ⋮ → «Установить приложение» или «Добавить на главный экран».
- **iPhone (Safari):** открой адрес → «Поделиться» → «На экран „Домой“».

После первого открытия приложение работает и без интернета.

## Обновление

Если меняешь `index.html`, увеличь версию в первой строке `sw.js` (`bzhu-v1` → `bzhu-v2`), иначе телефон может показывать старую версию из кэша.

## Данные

Дневник, норма и свои продукты хранятся только на устройстве. Для переноса на другой телефон: «Резервная копия» → «Сохранить в файл», затем на новом устройстве «Загрузить из файла».
Если удалить приложение или очистить данные сайта в браузере, дневник сотрётся, поэтому иногда сохраняй резервную копию.
